# EL SISTEMA

App personal de misiones con avisos, experiencia, castigos y rangos. Interfaz holográfica.

- `npm install` · `npm run dev` · `npm run build`
- Datos guardados en el dispositivo (localStorage). Sin servidor todavía.
- Contenido (horario, misiones, entreno, rangos) en `src/data.ts`; reglas en `src/engine.ts`.
